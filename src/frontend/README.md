## Desarrollo de la interfaz de usuario con Streamlit.

Es necesario descargar del repositorio la carpeta /src/frontend, y situarse en ella. Una vez descargada, debe configurarse un entorno Python con las dependencias indicadas en el fichero de reqerimientos, como se indica a continuación:

- *py -3.13 -m venv entorno_frontend*
- *entorno_api\Scripts\activate.bat*
- *python -m pip install --upgrade pip*
- *python -m pip install -r requirements_frontend.txt*

Para lanzar la app, ejecutar:

**python -m streamlit run app.py**
